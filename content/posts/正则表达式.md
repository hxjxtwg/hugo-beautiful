总结刮削影视文件的命名正则表达式

<!--more-->

### 一、常用表达式

#### 1. 开头+文件名

```
^(.+?)
```

#### 2. 空格

```
\s*
```

#### 3. 年份

```
(\d{4})
```

#### 4. 季与节

```
(S\d+)(E\d+)
```

或

```
(S\d+E\d+)
```

或

```
(S\d{2})(E\d{2})
```

(S\d{2}E\d{2})
```

#### 5. 省略部分

```
\..*
```

#### 6. 后缀+结尾

```
\.(.*)$
```

### 二、常用改名

#### 1. 在前面+名称

第一行：

```
^(.*)$
```

第二行：

```
名称.$1
```

#### 2. 空格集改标准

示例：神墓 - S03E01 - 第 01 集.mkv

第一行：

```
^(.+?)\s*-\s*(S\d{2}E\d{2})\s*-\s*第\s*(\d{2})\s*集\.(mkv|mp4)$
```

或

```
^(.+?)\s*-\s*(S\d+E\d+)\s*-\s*第\s*(\d+)\s*集\.(.*)$
```

第二行：

```
$1.$2.2026.$4
```

或

```
$1.$2.$4
```

#### 3. 去编码信息

示例：玄界之门.S01E09.2025.2160p.WEB-DL.H264.AAC.mp4

第一行：

```
^(.*?)\.(S\d+)(E\d+)\.(\d{4})\..*\.(.*)$
```

或

```
^(.*?)\.(\d{4})\.(S\d+E\d+)\..*\.(.*)$
```

第二行：

```
$1.$2$3.$4.$5
```

或

```
$1.$2.$3.$4
```


#### 4. 去英文名

源文件: 神话.my moontv.2025.S02E01.2160p.MAX+.HDR.60fps..WEB-DL.HEVC.10bit.DDP.mp4

源文件: 神话.my moontv.S02E01.2025.2160p.MAX+.HDR.60fps..WEB-DL.HEVC.10bit.DDP.mp4

第一行：

```
^(.+?).*\.(\d{4})\.(S\d{2}E\d{2})\..*\.(.*)$
```

或

```
^(.+?)\..*\.(S\d{2}E\d{2})\.(\d{4})\..*\.(.*)$
```

第二行：

```
$1.$2.$3.$4
```
